# shattrath

A public, personal knowledge base of tips and tricks across various topics — kept here to share with others.

It's deliberately simple: plain Markdown, nothing to build or run. The structure is **flat, one folder per topic** at the repo root. Each topic folder is self-contained and starts with its own `README.md` describing what's inside and why you'd read it.

## Topics

| Topic | What it covers |
|---|---|
| [cowork/](cowork/) | Claude Cowork best practices — skills, memory, workflow architecture, prompt engineering, how Cowork differs from Claude Code, and a practitioner-delta + Customer Success Manager playbook. |

## Conventions

- One folder per topic, no nesting beyond the topic folder.
- Every topic folder opens with a `README.md` index.
- Where docs make non-obvious claims, they cite sources inline and end with `Sources` and `Confidence & gaps` sections.
- Dates are written absolutely (e.g. `2026-05-18`), and time-sensitive material carries a researched-on date.
